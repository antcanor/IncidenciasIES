incidencias_ui

Componentes Flutter compartidos para la aplicación de incidencias del centro. La idea es tener en un mismo paquete las piezas que se reutilizan en varias pantallas y poder probarlas sin levantar toda la aplicación.

Features

  • PriorityBadge: etiqueta de prioridad editable o solo informativa.
  • IncidentCard: tarjeta con datos, estado y acciones de una incidencia.
  • MaquetaArBadge: marca visual para prototipos de la vista AR.

Getting started

El paquete se usa como dependencia local desde la aplicación principal:

dependencies:
  incidencias_ui:
    path: packages/incidencias_ui

Usage

Ejemplo mínimo de una etiqueta:

PriorityBadge(
  priority: Priority.medium,
  onChanged: (priority) {
    // Actualizar la incidencia.
  },
)

Documentación

La API pública está comentada en español y la documentación HTML generada se encuentra en ../../docs/api. Para regenerarla desde la raíz del repositorio:

cd packages/incidencias_ui
dart doc --validate-links --output=../../docs/api
